 Container Examples
How to use
This directory will contain containerized application setups and workflow examples. Please refer to CCR's container documentation for more information.
Installing Linux Packages
Some software may require additional Linux packages as dependencies when being installed inside a container. The packages needed will depend on the software and its specific requirements. More information about software requirements and dependencies can be found in CCR's software policies and container documentation.
Examples of software-specific container definition files that install Linux packages can also be found in the advanced directory and can be used as a reference when creating your own container.
